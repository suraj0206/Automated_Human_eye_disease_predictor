# Resume Bullets

**Automated Retinal Disease Screening System | ResNet50, Random Forest, Streamlit**

- Developed a multi-label retinal disease screening pipeline using ImageNet-pretrained ResNet50 feature extraction and One-vs-Rest Random Forest classification.
- Combined bilateral fundus-image representations with patient age and sex metadata for classification across eight ocular disease categories.
- Converted the research notebook into a GitHub-ready project with documented data, model pipeline, evaluation workflow, architecture, and Streamlit showcase.
